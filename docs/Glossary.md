# Glossary

| Term          | Definition |
| ------------- |-------------|
| EP            | Short for ExecutionPlatform.      |
| DUT           | Device under Test. The microcontroller that is built into your device. |
| BSP           | Board Support Package. |
| Code Interface           | Mechanism for tests to call DUT software functions. |
| Endpoint                 | Mechanism for tests to observe and control DUT periphery (MCU Pins). |
| Robot                    | Short for [Robot Framework](https://robotframework.org/). All EP functionality is accessed through sequences written in Robot. |
